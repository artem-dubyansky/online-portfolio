# Навигатор будущего

Образовательная платформа для старшеклассников: исследование профессий, проверка интересов на практике, развитие навыков и создание личного образовательного маршрута.

## Разделы платформы

1. Профориентация — короткий тест из шести вопросов. Результат показывает направление для дальнейшего исследования, а не определяет профессию за пользователя.
2. Мир профессий — каталог профессий с описанием задач и полезных навыков.
3. Практика и проекты — задания по инженерии, IT, науке, бизнесу и дизайну.
4. Образование — планирование предметов, курсов и самостоятельного обучения.
5. Мой маршрут — личный список шагов с отметками выполнения.
6. Портфолио — профиль, проекты, достижения и резервное копирование.
7. Возможности — раздел для будущего каталога олимпиад, конкурсов и мероприятий.
8. Поступление — личный список интересующих учебных заведений.

## Технологии текущей версии

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Progressive Web App (PWA)

## Запуск и публикация

Проект рассчитан на публикацию через GitHub Pages. Для локальной проверки можно открыть `index.html` или запустить любой статический HTTP-сервер. Для полноценной проверки PWA нужен HTTPS или localhost.

## Хранение данных и ограничения

Профиль, результаты теста, проекты, достижения, маршрут и список учебных заведений сохраняются в LocalStorage браузера. Данные остаются на текущем устройстве и в текущем браузере; регистрации, серверной базы и синхронизации между устройствами пока нет.

Разделы «Образование» и «Возможности» не содержат автоматически обновляемого каталога. Курсы, конкурсы, даты, правила приёма и проходные баллы нельзя считать актуальными без проверки официальных источников.

## Установка как приложение

В репозитории есть манифест, service worker и масштабируемые SVG-иконки 192×192 и 512×512. Возможность установки зависит от браузера, платформы и условий PWA. GitHub Pages предоставляет HTTPS.

## План дальнейшей разработки

- Backend на Node.js.
- PostgreSQL и серверное хранение профилей.
- Регистрация, авторизация и синхронизация между устройствами.
- Проверяемый каталог образовательных возможностей с датой обновления и ссылкой на официальный источник.
- Расширенный второй профориентационный тест.
- Проектная лаборатория с сохранением результатов практических заданий.
- Экспорт портфолио в PDF.
- C++/WebAssembly только для конкретных алгоритмов, если они действительно понадобятся.

Пункты из плана развития не реализованы в текущей статической версии.
