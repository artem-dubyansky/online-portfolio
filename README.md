
# Навигатор будущего

Образовательная платформа для исследования профессий, развития навыков и построения индивидуального образовательного маршрута.

## Разделы

1. Профориентация
2. Мир профессий
3. Практика и проекты
4. Образование
5. Мой маршрут
6. Портфолио
7. Возможности
8. Поступление

## Технологии

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Progressive Web App

## Запуск

Проект можно опубликовать через GitHub Pages.

## Хранение данных

Профиль, проекты, достижения и маршрут сохраняются в LocalStorage браузера. Данные не синхронизируются между устройствами.

## Дальнейшее развитие

- Backend на Node.js
- PostgreSQL
- Регистрация и авторизация
- Синхронизация профиля
- Проверенный каталог образовательных возможностей
