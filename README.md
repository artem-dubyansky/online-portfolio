# Навигатор будущего

Образовательная платформа для старшеклассников: исследование профессий, проверка интересов на практике, развитие навыков и создание личного образовательного маршрута.

## Разделы платформы

1. **Профориентация** — короткий тест из шести вопросов. Результат предлагает направление для исследования, а не выбирает профессию за пользователя.
2. **Мир профессий** — каталог профессий с описанием задач и полезных навыков.
3. **Практика и проекты** — задания по инженерии, IT, науке, бизнесу и дизайну.
4. **Образование** — личный список курсов, кружков, летних школ и самостоятельного обучения. Записи добавляются вручную со ссылкой на официальную страницу.
5. **Мой маршрут** — личный список шагов с отметками выполнения.
6. **Портфолио** — анкета, проекты, структурированные достижения и фотографии грамот; экспорт в Word, TXT, печать/PDF и техническая JSON-резервная копия.
7. **Возможности** — личный каталог олимпиад, конкурсов, хакатонов, мероприятий и летних программ с организатором, сроками, условиями и официальной ссылкой.
8. **Поступление** — список школ, колледжей и университетов, направлений, экзаменов, сроков и статусов интереса.

В разделах «Образование» и «Возможности» нет автоматически обновляемой базы мероприятий. Пользователь добавляет запись только после самостоятельной проверки организатора, сроков и условий по официальному источнику. Даты и условия могут меняться, поэтому их необходимо перепроверять.

## Технологии текущей версии

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Progressive Web App (PWA)

## Запуск и публикация

Проект рассчитан на публикацию через GitHub Pages. Для локальной проверки можно открыть `index.html` или запустить статический HTTP-сервер. Для полноценной проверки PWA нужен HTTPS или localhost.

## Хранение данных и ограничения

Профиль, результаты теста, проекты, достижения, маршрут, учебные заведения, образовательные программы и возможности сохраняются в LocalStorage браузера. Данные остаются на текущем устройстве и в текущем браузере; регистрации, серверной базы и синхронизации между устройствами пока нет.

Фотографии грамот уменьшаются перед сохранением, но место в LocalStorage ограничено. При большом количестве изображений браузер может отказать в сохранении. Рекомендуется хранить оригиналы отдельно и периодически скачивать резервную копию. JSON предназначен для резервного копирования и не является основным документом портфолио.

Word-экспорт формируется как HTML-документ с расширением .doc для открытия в совместимом редакторе. Для PDF используется системное окно печати браузера: выбери «Сохранить как PDF».

## Установка как приложение

В репозитории есть манифест, service worker и SVG-иконки. Возможность установки зависит от браузера, платформы и условий PWA. GitHub Pages предоставляет HTTPS.

## План дальнейшей разработки

- Backend на Node.js.
- PostgreSQL и серверное хранение профилей.
- Регистрация, авторизация и синхронизация между устройствами.
- Проверяемый каталог образовательных возможностей с обновлением и ссылкой на официальный источник.
- Второй профориентационный тест.
- Проектная лаборатория с сохранением результатов практических заданий.
- C++/WebAssembly только для конкретных алгоритмов, если они действительно понадобятся.

Пункты из плана развития не реализованы в текущей статической версии.
